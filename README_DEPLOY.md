# VEX Override Selection 2026–2027

Website chấm tuyển V5RC Override cấp trường, gồm Engineering Notebook, phỏng vấn kỹ thuật, thiết kế robot, Autonomous Skills và Driver Skills.

## GitHub Pages

Các tệp website tĩnh nằm ngay ở thư mục gốc. Trong repository GitHub:

1. Mở **Settings > Pages**.
2. Trong **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh mặc định và thư mục **/(root)**.
4. Bấm **Save**.

Website dự kiến xuất hiện tại:

`https://huynhbaothienlsts.github.io/Vex2627/`
